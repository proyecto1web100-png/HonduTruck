# HonduTruck

Propuestas de sitio web para Hondu Truck (accesorios y repuestos para camión, Honduras).

`index.html` muestra las cinco propuestas en una sola página con un selector arriba. Cada propuesta se puede enlazar directo con `#propuesta-1` a `#propuesta-5`.

- `1/` Versión clara
- `2/` Noche y cromo
- `3/` Institucional
- `4/` Catálogo técnico
- `5/` Cabina (glassmorphism)

Sitio estático publicado con GitHub Pages. El número de WhatsApp y el factor de precio están al inicio del script (versión 1 en `1/index.html`; versiones 2 a 5 en `core.js`).
