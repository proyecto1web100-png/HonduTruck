# HonduTruck

Propuestas de sitio web para Hondu Truck (accesorios y repuestos para camión, Honduras).

- `1/` Versión clara
- `2/` Noche y cromo
- `3/` Mostrador

Sitio estático publicado con GitHub Pages. El número de WhatsApp y el factor de precio están al inicio del script (versión 1 en `1/index.html`; versiones 2 y 3 en `core.js`).
